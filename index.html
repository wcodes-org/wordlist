WCode Wordlist

Base-1024 single source of truth for digital word encoding and decoding.

Endpoints

  • /wordlist.json JSON (1,024 words)
  • /wordlist.js Browser SDK / Global dictionary
  • /wordlist.txt Plain text (newline-delimited)
  • /Wordlist.tsv Categorized TSV with metadata
  • /Wordlist-black.tsv Blacklisted / discarded words TSV

CORS & Edge Caching

All endpoints allow cross-origin requests (Access-Control-Allow-Origin: *) and are cached at the Cloudflare edge.
